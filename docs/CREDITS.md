## Scope

This record identifies the project creators. It does not change third-party
licenses, historical validation evidence, App Store seller identity, or the
legal-controller and App Review contact fields, which require owner/legal
confirmation.

The deterministic repository check is `python3
scripts/release-readiness/verify_documentation_credits.py`. It verifies only
project-authored Markdown in its documented scope; it does not alter or
reinterpret third-party license materials.
