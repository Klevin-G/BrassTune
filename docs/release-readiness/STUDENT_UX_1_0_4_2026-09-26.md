## Boundaries

Apple approval/public release is pending. New code generation is numeric; legacy codes are intentionally compatible. Physical acoustic evidence includes an uncalibrated Mac-played A440 reference and repeated phone audio operations; it does not certify every instrument, room, accessory, or hearing environment. The higher volume ceiling is verified digital gain/headroom, not a calibrated SPL claim. No universal bug-free guarantee follows from these finite checks.
