# Friend QA Script

Use disposable data only. Do not upload private student recordings.

1. Open the app URL the owner gives you.
2. Select `Continue as guest` if you see account setup.
3. Complete setup and choose your instrument.
4. Start demo practice and confirm the tuner view is understandable.
5. Start a short take, stop it, and open the saved session review.
6. Confirm the review has useful metrics and recommendations.
7. Try microphone mode. If prompted, allow or deny permission and note whether the status message is clear.
8. Import a saved audio or video file. Confirm the source file stays on your device unless you are signed in.
9. Visit Sign in. Confirm account status is understandable.
10. Visit Sessions, Settings, Privacy, Terms, and Support.
11. Report anything confusing, broken, slow, clipped, or unexpected.

## Expected Results

- Basic practice does not require sign-in.
- Guest sessions say they stay on this device.
- Account features clearly say they require beta account setup when unavailable.
- No normal user screen asks you to set env vars or start a backend server.
- Import language says audio/video recording, not camera.
