# Google sign-in font

`GoogleSans-Medium.woff2` is a web subset of the canonical
`swift/BrassTuneApp/BrassTuneApp/Resources/Fonts/GoogleSans-Medium.ttf`.
It contains the characters used by BrassTune's localized Google sign-in
labels; unsupported scripts fall back to the platform sans-serif font.

The font is distributed under the SIL Open Font License in
[`frontend/public/licenses/GoogleSans-OFL.txt`](../../../public/licenses/GoogleSans-OFL.txt),
which Vite copies into every production build.
